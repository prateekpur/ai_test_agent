## SauceDemo Login - Successful Authentication

Test successful login to https://www.saucedemo.com/ using Playwright.

Test flow:
1. Navigate to https://www.saucedemo.com/
2. Verify the login page loads with username and password fields
3. Enter username: "standard_user"
4. Enter password: "secret_sauce"
5. Click the "Login" button
6. Verify redirect to inventory page (URL contains "/inventory.html")
7. Verify "Products" heading is visible
8. Verify at least one product is displayed (e.g., "Sauce Labs Backpack")

Locators to use:
- Username field: [data-test="username"]
- Password field: [data-test="password"]
- Login button: [data-test="login-button"]
- Products heading: text "Products"
- Inventory page URL: https://www.saucedemo.com/inventory.html

Expected result: User is logged in and sees the product inventory page.

## SauceDemo Login - Session Persistence

Test that login session persists across page navigation.

Test flow:
1. Navigate to https://www.saucedemo.com/
2. Login with username: "standard_user" and password: "secret_sauce"
3. Verify redirect to inventory page
4. Navigate directly to https://www.saucedemo.com/cart.html
5. Verify user is still logged in (not redirected to login page)
6. Navigate to https://www.saucedemo.com/inventory.html
7. Verify user is still logged in
8. Open menu and click logout
9. Verify redirect to login page
10. Attempt to navigate to https://www.saucedemo.com/inventory.html
11. Verify redirect back to login page (session ended)

Expected result: Session is maintained until logout.
